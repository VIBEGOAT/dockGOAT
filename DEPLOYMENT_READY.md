## 🌐 Deployment Path (3 Steps)

### Step 1: Add Environment Variables
Collect these values before deploying:

```
MONGODB_URI=<from MongoDB Atlas>
NEXT_PUBLIC_SUPABASE_URL=<from Supabase>
NEXT_PUBLIC_SUPABASE_ANON_KEY=<from Supabase>
NEXT_PUBLIC_SUPABASE_STORAGE_BUCKET=dockgoat-files
SUPABASE_URL=<from Supabase>
SUPABASE_SERVICE_KEY=<from Supabase>
HF_SPACE_API_URL=<your HF Space URL>
HF_SPACE_API_KEY=<your HF token>
```

### Step 2: Deploy to Vercel
1. Go to https://vercel.com
2. Click "Add New..." → "Project"
3. Import VIBEGOAT/dockGOAT repo
4. Add environment variables from Step 1
5. Click "Deploy"
6. **Wait 2-3 minutes**
7. Get live URL! 🎉

### Step 3: Configure Services
- Set up MongoDB Atlas cluster
- Create Supabase project & storage
- Deploy HF Spaces worker
- Test end-to-end
